# pajamaw.github.io

My personal site. It's Jekyll, and GitHub Pages builds it from `master`.

    bin/post new "Title"     # new post in _posts/, dated today
    bin/post draft "Title"   # new draft in _drafts/
    bin/post serve           # local preview (needs jekyll)
    bin/post publish         # commit + push, live in ~1 min

Run `bin/post` with no arguments to see every command.
